Install CROW

From download to first login takes about ten minutes.

  1. Download the ISO

    Use the download button above, then verify the checksum:

    sha256sum crow-linux.iso

  2. Make a bootable USB drive

    You need a drive of at least 8 GB. Everything on it will be erased. On Windows use Rufus or Ventoy. On Linux:

    sudo dd if=crow-linux.iso of=/dev/sdX bs=4M status=progress oflag=sync

  3. Boot from the USB drive

    Restart and press the boot menu key (usually F12, F2 or Esc). If it does not boot, turn off Secure Boot in the BIOS.

  4. Click Install at the top right

    CROW starts in live mode. Look at the top-right corner of the screen: the Install button sits in the top panel, just left of the camera icon. Click it to open the installer.

    Top-right of the screen: click Install

  5. Follow the installer steps

    • Choose your language and keyboard layout
    • Select your time zone
    • Choose the disk to install on
    • Create your username and password
    • Review the summary and start the installation

  6. Restart

    When the installation finishes, remove the USB drive and restart. Log in from the CROW login screen.

FAQ

Answers to common questions.

What is the live session password?

The live user is liveuser. If it asks for a password, press Enter, or enter the password listed here.

Does it run in a virtual machine?

Yes. In VirtualBox or VMware, enable 3D acceleration and give it at least 4 GB of RAM.

Is NVIDIA supported?

Yes, but you may need to install the proprietary driver.
